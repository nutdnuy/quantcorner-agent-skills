QUANTCORNER FIELD GUIDE

Start with the right building block.

A skill, an agent, and a research framework serve different jobs. This library keeps their requirements visible.

Individual skills & collections

Each individual skill links to a specific SKILL.md. Collections group multiple skills in one repository and are counted separately. Check the listed agent compatibility and follow the source installation instructions.

MCP servers

Connect an MCP-compatible assistant to external data and tools. Check authentication, provider plans, and whether tools can change state before configuring a connection.

AI agents

Applications that coordinate research tasks. They may require Python, model API keys, data access, and separate setup. They are not drop-in Claude Code skills.

Research frameworks

Libraries for data, backtesting, and portfolio analysis. Use their documented APIs in your research environment; agent integration requires additional work.

Repository descriptions are source-based summaries. Runtime behavior, investment results, and security have not been audited by QuantCorner.
